# Clean code VS Dirty code

## Qu'est-ce que du code sale ?

- Du code pas du tout commenté(à quoi sert la méthode) ou pas à jour
- Des variables et des méthodes avec des noms non explicites(qui peuvent remplacer la présence de commentaires)
- Variables et paramètres pas utilisés
- Longue fonctions/méthodes (qui pourraient être découpées)
- Obsolescence dependances / langage
- Code spaghetti, dupliqué ou pas structuré

## Qu'est-ce que du code propre ?

- Des commentaires utiles, mis à jour et pertinent qui rajoutent une plus value(définit les paramètres et les sorties ainsi que le fonctionnement de la méthode)
- Respect conventions explicite + auto (linter)
- Historique MAJ clair
- Structure de code
